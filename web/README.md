# 网页版（单文件 PWA）

这一版是一个自包含的单文件页面 `声笺.html`（约 58 KB，1400 行）：CSS、JS、图标、字体链接全部内联在内，没有任何构建步骤，也没有依赖目录。

## 为什么这个目录里只有说明文件

单文件 58 KB 的内联页面不方便用逐文件的文本接口搬运（很容易在搬运中被截断或改掉一个字符，仓库里就会出现一份“看起来能用、实际和线上不一样”的副本），所以这个目录暂时只放说明。

要把它纳入仓库，两种方式都行：

1. **直接把文件拖进去**：在 GitHub 仓库页面进入 `web/`，点 “Add file → Upload files”，把本地的 `声笺.html` 拖进去提交。
2. **让我再推一次**：跟对话里说一声，我用文本接口把它整份提交上来。

## 运行要求

麦克风权限只在安全上下文开放，所以必须走 **https 或 localhost**，直接双击打开 `file://` 会拿不到麦克风（录音浮层会显示“拿不到麦克风权限”）。

部署：把 `声笺.html` 丢到任意支持 https 的静态托管即可（对象存储 / Vercel / GitHub Pages）。

## 已经实现的能力

| 环节 | 实现 |
| --- | --- |
| 录音 | `MediaRecorder`，webm/opus 优先，iOS 回退 mp4；音频存 IndexedDB，刷新不丢 |
| 转写 | 浏览器内置 `SpeechRecognition`，边说边出字，连续识别自动重启 |
| 翻译 | 19 种语言多目标并行；自建 OpenAI 兼容接口 → Google gtx → MyMemory 三级降级 |
| 朗读 | `speechSynthesis` 按目标语言自动匹配音色 |
| 克隆音色 | 用户自填 endpoint（POST text/language/voice_id），支持二进制或 audio_url / audio_base64 |
| 记录 | 今日/累计/目标语言统计，按天分组，听原声、读译文、复制、删除、导出 JSON |
| 设置 | 输入语言、目标语言多选、翻译引擎、TTS/克隆接口、声音样本录制、清空 |

## 如实说明的不足

- 转写是浏览器的，不是自建 ASR：Chrome 依赖 Google 服务，国内大概率不通；Safari 走系统听写通常可用。识别不可用时录音仍保存，可手动补文字。
- 免费翻译接口有频率与长度限制（MyMemory 单次约 480 字符），失败时会在译文位置如实显示“翻译失败（原因）”。
- 浏览器没有真正的声音克隆，默认是系统音色；克隆音色需要你自己填接口和音色 ID，未配置时界面明确标注“系统音色”。
